# Flex Motors

Site institucional do Centro Automotivo Flex Motors, desenvolvido com Vite e JavaScript.

## Executar localmente

```bash
npm install
npm run dev
```

## Gerar versão de produção

```bash
npm run build
```

Os arquivos gerados ficam em `dist/`.

## Estrutura do projeto

- `src/`: componentes, conteúdo e estilos do site.
- `public/images/`: logo e imagens usadas pela página.
- `index.html`: documento principal.

Para importar manualmente no v0, envie o repositório ou os arquivos do projeto. O comando de desenvolvimento é `npm run dev`; a saída estática de produção é `dist/`.
